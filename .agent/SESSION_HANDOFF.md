## Previous session scope (historical; retail override above is current)

RetailPlus is an enterprise workspace for ingesting business data, understanding its structure, cleaning and organizing it with traceable changes, validating it, then eventually producing analytics, optional ML predictions, dashboards, and exports. The working slice is authenticated CSV import and a saved, editable dataset sheet. Multi-format ingestion, categories, analytics, prediction, and assistant UI are future work unless code proves otherwise.

Target flow: sign in -> select or create a workspace -> Data / Datasets -> list existing datasets or add a CSV by drop/browse -> upload and process -> open the saved sheet -> inspect compact processing status, edit cells/rows, export organized CSV or change log. Workspace membership scopes API data. With no workspace, workspace naming is required.

The logical pipeline in `docs/agent-workflow.md` is ingestion -> understanding -> cleaning -> organization -> validation -> analytics -> prediction eligibility -> dashboard -> export. These are product stages, not nine running AI agents. Currently implemented: basic CSV parsing, field aliases, profiling, whitespace/empty value normalization, missing-value validation, exact duplicate removal, fuzzy duplicate suggestions retained for review, and CSV/change-log export. Category discovery or naming is **not implemented**; an LLM is a possible reviewed naming aid, not a prerequisite for basic cleaning. Preserve IDs as text and never invent missing values.
