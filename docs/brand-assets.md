# RetailPlus brand asset

Generated with the built-in `image_gen` tool on 2026-10-29, then copied into the repository. No API/CLI fallback was used. The original generated file was preserved.

Final asset: `apps/admin-dashboard/public/brand/retailplus-cart-plus.png`.

PNG inspection: RGBA, 1374 × 1145, alpha range 0–255. It has an actual transparent background. Used by the shared `Brand.tsx`, landing page, workspace chooser and favicon. Category/product icons use the existing Lucide vector system instead of raster thumbnails, with different shapes/colors for audio, electronics, clothing, footwear, accessories, home, kitchen, fitness and stationery.

## Generation prompt

Use case: logo-brand. Asset type: transparent PNG app brand mark for RetailPlus, a refined retail analytics workspace. Create one original compact shopping-cart-plus symbol, no lettering, no wordmark. A clean geometric shopping cart with two round wheels and an integrated clearly recognizable plus sign rising at the upper-right. Refined flat vector-like rendering with slightly rounded corners, confident simple silhouette, thick enough for a 28px sidebar icon. Palette: mint green #79e6a4 and dark pine #254333 with a small warm coral #ed8652 plus sign. Balanced centered composition, generous transparent margin, no background, no badge, no enclosing rounded square, no texture, no shadow, no 3D, no glow, no gradients, no watermark. Transparent alpha background. Intended to work as a small web app logo beside the RetailPlus wordmark.

## Customer profile placeholders

CustomerAvatar.tsx generates deterministic SVG illustrations locally using DiceBear v10 and the **Notionists Neutral** style (CC0, remix of Notionists by Zoish). [Style and license](https://www.dicebear.com/styles/notionists-neutral/). A stable customer/name seed gives each profile a repeatable placeholder; these are not photographs or inferred identities. Names are never sent to an avatar service. The avatar module is loaded only when needed, with initials as a fallback.
